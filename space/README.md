# PHC Scribe API (v1)

Structured antenatal-visit documentation for Nigerian primary health care, built on N-ATLaS. A documentation aid: it drafts, a health worker confirms. It never gives advice or a diagnosis.

Interactive docs: `/docs`. Guide: `docs/api.md` in the project repository. Every endpoint except `/v1/health` needs an API key (`Authorization: Bearer <key>`).
