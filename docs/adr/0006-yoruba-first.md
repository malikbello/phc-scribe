# ADR-0006: Yoruba first, English alongside

- **Status:** Accepted
- **Date:** 2026-09-29

## Context
Malik is a native Yoruba speaker, and the clinical adviser is at UCH Ibadan. Yoruba has N-ATLaS's lowest AfroBench baseline (38.4), which leaves the most room for a measurable gain.

## Decision
Launch language pair is Yoruba + English. Hausa, Igbo and Pidgin are i18n and model slots for later.

## Consequences
Northern rollout needs Hausa data and reviewers later. Yoruba diacritics need normalisation-aware metrics.
